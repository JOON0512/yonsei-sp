# 시스템프로그래밍 학습 기록

2024년 가을 시스템프로그래밍 학습과 관련된 저장소입니다. 현재 보관된 보고서는 확인했지만, 당시 제출한 커널 모듈 소스 압축파일은 아직 복원하지 못했습니다. 당시 VM 재부팅 문제의 원인을 원본 코드에서 확인하거나 수정했다고 주장하지 않습니다.

관련 개념을 다시 공부하며 새로 설계한 개인 프로젝트는 [proc-lens](https://github.com/JOON0512/proc-lens)에 있습니다. 읽기 전용 프로세스 스냅샷, 참조 수명 관리, 작업 취소와 모듈 제거를 구현했으며 Linux 6.8 VM에서 반복 조회·부하·50회 삽입/제거를 검증했습니다. 이 프로젝트는 과거 제출물을 이름만 바꿔 게시한 자료가 아닙니다.
