# 시스템프로그래밍 학습 기록

2026-10-25에 LearnUs에서 본인의 원래 커널 모듈 제출 압축파일을 복원했습니다. 반복 조회 중 잘못된 메모리 해제와 모듈 제거 중 잠금 문제를 Linux 6.8 VM에서 재현했고, 로컬 수정본은 반복 조회·프로세스 생성·제거 테스트를 통과했습니다. 상세한 원인과 검증 범위는 [디버깅 기록](debugging.md)에 정리했습니다.

수업 자료에 웹 공개 금지 안내가 있어 원본 과제와 그 파생 수정본은 로컬에 보관합니다. 공개 저장소에는 원본 코드를 재게시하지 않고 원인 분석과 새로 설계한 독립 프로젝트를 안내합니다.

[proc-lens](https://github.com/JOON0512/proc-lens)는 별도로 새로 구현한 읽기 전용 프로세스 스냅샷 모니터입니다. 참조 수명 관리, 작업 취소와 모듈 제거를 구현하고 Linux 6.8 VM에서 검증했습니다. 원래 제출물을 이름만 바꾼 프로젝트나 원본의 동일한 패치라고 설명하지 않습니다.
